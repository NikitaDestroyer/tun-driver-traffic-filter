# VPN-сигнатуры

Модуль `kernel/tun_vpn_detect.c` использует эвристики из `kernel/vpn_signatures.h`.
Payload читается через `skb_copy_bits()` (безопасно для нелинейных skb).

## WireGuard

| Условие | Детали |
|---------|--------|
| Протокол | UDP |
| Порт | 51820 (src или dst) |
| Структура | Первый байт тип сообщения 1–4; handshake ≥ 92 байт (тип 1–2) или data ≥ 32 байт |

## OpenVPN

| Условие | Детали |
|---------|--------|
| Порт | 1194 TCP или UDP |
| Payload | Первый байт: opcode = `(byte >> 3)`, opcode 1–8 (control) |

## IKE/IPsec (IKEv2)

| Условие | Детали |
|---------|--------|
| Порт | UDP 500 или 4500 |
| Структура | Payload ≥ 28 байт; major version = 2 в байте 17 (MjVer) |

## Ограничения

- Только **IPv4**.
- Детект только на трафике **tun0** / lab veth → IP tun0.
- Порт без структурной проверки для WireGuard/IKE допускается при достаточной длине payload (lab-тесты).

## Ложные срабатывания

Снижены по сравнению с «только порт»: OpenVPN opcode не срабатывает на произвольный UDP с byte ≤ 8 без сдвига >> 3.
