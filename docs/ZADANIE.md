# Задание 
Тема:
"Разработка виртуального сетевого интерфейса с функциями мониторинга и фильтрации трафика на основе TUN-драйвера Linux"

Цель работы:
Разработать программный комплекс на базе TUN-драйвера ядра Linux, реализующий виртуальный сетевой интерфейс с возможностью перехвата, анализа и фильтрации IP-трафика в режиме реального времени.

Драйвер должен выявлять сигнатуры минимум трёх разных VPN-решений и выводить в консоль ядра сообщения о новых подключениях, с указанием общающихся сторон, вплоть до портов. Вывод в консоль не должен происходить непосредственно во время фильтрации трафика
## Что сделано в проекте

| Требование | Реализация |
|------------|------------|
| TUN-интерфейс | `src/tun_iface.c` — `/dev/net/tun`, интерфейс `tun0` |
| Перехват IP-трафика | `src/main.c` — read/write пакетов |
| Парсинг TCP/UDP/ICMP | `src/packet_parser.c` |
| Фильтрация | `src/filter.c` + `config/rules.conf` |
| Лог без вывода в hot path | `src/log_queue.c` — очередь + поток |
| 3 VPN-сигнатуры | `kernel/tun_vpn_detect.c` — WireGuard, OpenVPN, IKE |
| Вывод в консоль ядра | `printk` только в `log_work_handler` (workqueue) |
| Не printk при фильтрации | hook возвращает `NF_DROP` без логов |

## VPN-сигнатуры (упрощённые)

1. **WireGuard** — UDP, порт 51820 (src или dst)
2. **OpenVPN** — TCP/UDP 1194 или opcode 1–8 в UDP payload
3. **IKE/IPsec** — UDP 500 или 4500
